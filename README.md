# iPad Legacy Apps - Cydia repo

Native apps for 32-bit iOS 10 (iPad 4 era), each installed on its own, plus a Jailbreak Setup.

Add this source in Cydia: **https://h2ixi.github.io/cydia/**

Jailbreak Setup: one tap installs AppSync Unified, appinst, Filza, PreferenceLoader and Apple File Conduit "2". Apps install one by one.
