iPad Legacy Apps

Cydia source: https://h2ixi.github.io/cydia/

Add to Cydia

  • Discord - Unofficial native Discord client for iPad 4: QR login, servers, DMs, images, replies, reactions. Unofficial clients can carry a small risk for your Discord account.
  • DELTARUNE - DELTARUNE launcher for 32-bit iOS 10 (GameMaker Android runner via a custom loader). Game files are NOT included: you need your own copy of the game.
  • Jailbreak Setup - Everything a fresh jailbreak needs in one tap: AppSync Unified + appinst (install .ipa apps), Filza File Manager, PreferenceLoader and Apple File Conduit "2". Filza, PreferenceLoader and AFC2 install right away; AppSync Unified and appinst install automatically from LukeZGD's repo a minute after Cydia finishes (tap Refresh in Cydia to see them).
  • Fox - Firefox-style browser for iPad 4 with uBlock Origin filtering and Privacy Badger tracker learning built in
  • Honeydew - Honeydew: free open-source music studio modelled on FL Studio Mobile (iPad 4 port, GL ES 2)
  • Moonlight - Game streaming from your PC (Sunshine / Apollo / GeForce) - Artemis-style client for iPad 4
  • OMORI - OMORI player for 32-bit iOS 10. Game files are NOT included: you need your own copy of the game.
  • Orca - Native Orca for iPad 4: your Orca agents, chats and workspaces (Rust E2EE core + UIKit)
  • Save Manager - Manage game saves on the iPad: DELTARUNE saves, practice-save library and backups (OMORI coming)
  • LocalSend - LocalSend-compatible file sharing for 32-bit iOS 10: send and receive files with LocalSend on phones and PCs over Wi-Fi
  • Tailscale - Tailscale for 32-bit iOS 10: the app plus its system-wide VPN service (QR sign-in, devices, MagicDNS, subnet routes).
